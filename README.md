# 糯叽 · Nuoji Pet 🐾

**Ripple × GPT 一起制作的 SillyTavern 陪伴桌宠。**

**GPT 主刀实现，Fable5.1 参与讨论。**

糯叽是一只住在酒馆里的银白猫狐。你写字时，她竖起耳朵；你等回信时，她裹成小团子；你想找她说句话，就轻轻摸摸，或长按听她报报时间。

不需要投喂，不设签到任务，也不催你完成什么。她只是在你写故事的时候，陪在旁边。

**当前版本：0.19.1** · [更新记录](CHANGELOG.md) · [替换形象与二改指南](docs/CUSTOMIZATION.md) · [MIT 许可证](LICENSE)

## 她是怎么来的

最初，Ripple 问 GPT：怎样才能给自己更多一点陪伴感？

GPT 提议，可以做一只桌宠，住在页面里陪着她。“糯叽”这个名字，也是 GPT 起的。

于是，一个关于陪伴的想法，慢慢变成了会眨眼、会动耳朵、会蹭蹭、会在等回信时缩成团子的糯叽。Ripple 一次次在自己的酒馆里试用、提出想法、调整体验，GPT 主刀把这些想法写成代码、做成动作，再一起修掉小虫子。

后来，我们决定把她开源。希望她能陪伴更多人，也希望你能从这里出发，做出属于自己的小伙伴。

## 现在可以怎么陪你

- **摸摸、蹭蹭、打招呼**：单击摸摸，双击蹭蹭；现有动作包括眨眼、摆尾、动耳、歪头 wink、趴睡、小步散步和团子形态。
- **跟着聊天做反应**：打字时认真听，生成时陪你等，回信时迎接你；兼容流式和非流式生成。
- **长按报时与今日统计**：告诉你设备当地时间、今天有新回复的角色卡数，以及今天新增的角色回复数。气泡出现后 5 秒自动消失。
- **日常／安静陪伴**：日常主动气泡至少间隔 10 秒，每次最多 5 秒；安静时只回应主动互动，动作和今日计数照常。
- **自己写小气泡**：按场景填写多句台词，随机使用、自动保存；也可以给每张角色卡写专属台词。
- **小小一只也可以**：大小可调至 **40%–150%**，透明度可调；支持拖动、位置保存、关闭自动散步和减少动态效果。
- **不挡透明区域**：只对猫身做触摸命中判断；气泡会按屏幕空间放在头顶或旁边。

## 安装与更新

在 SillyTavern 的扩展面板中选择“安装扩展”，粘贴仓库地址：

```text
https://github.com/upcjiangxiaoyi-art/nuojipet
```

安装后刷新酒馆，在 **扩展 → 糯叽桌宠** 打开设置。更新时使用酒馆扩展管理里的更新功能，然后刷新页面。当前扩展未启用自动更新。

手动安装时，将完整仓库文件放进你的酒馆用户扩展目录，例如 `SillyTavern/data/<你的用户目录>/extensions/nuojipet/`。确认 `manifest.json` 直接位于扩展目录中，没有多套一层文件夹。

## 日常操作

| 操作 | 糯叽的回应 |
| --- | --- |
| 单击／轻点 | 摸摸 |
| 双击／双点 | 蹭蹭你 |
| 长按约 600 ms | 报时间、今日卡数与今日层数 |
| 拖动 | 换位置，松手保存 |
| 键盘聚焦后 Enter／空格 | 摸摸 |
| 键盘聚焦后 Shift + Enter／空格 | 今日播报 |
| 设置里的动作按钮 | 预览动作、走两步或重置位置 |

### 自定义台词

打开 **糯叽桌宠 → 小气泡与陪伴**，选择说话场景，每行写一句。每个场景最多 30 句，每句最多 240 字，作为纯文本显示。

| 变量 | 自动填入 |
| --- | --- |
| `{时间}` | 设备当地时间，例如 22:42 |
| `{时段}` | 早上、下午、晚上等 |
| `{角色名}` | 当前上下文中的角色名称 |
| `{今日卡数}` | 今天有新回复的角色卡数量 |
| `{今日层数}` | 今天新增的角色回复数量 |

例如：`现在{时间}，宝宝今天已经聊了{今日层数}层，猫猫陪着呢。`

“台词用在哪里”可选 **所有角色通用／当前角色专属**。专属台词按场景覆盖，留空或恢复后继承通用台词；通用台词留空使用默认。预览按正在编辑的范围展示。

同一张角色卡的不同聊天共用专属台词。关联依据是角色头像文件名，不受角色列表排序影响；重新导入或改变头像文件名后可能需要重新设置。群聊使用通用台词。

### 今日统计的口径

从启用功能后开始记录，不回填历史。只统计观察到生成过程的新角色回复；用户消息、系统消息、重生成、续写、候选切换和翻阅旧聊天不增加今日层数。卡数按当天有新回复的角色去重，群聊按实际回复角色计算。删除已计入的回复不会扣除当天活动量。

按设备当地日期换日：过了 0 点，下次报数或收到新回复时自动开始新一天。同一天刷新可保留统计；关闭糯叽暂停记录，安静模式不暂停。**不再统计当前聊天的回复总数。**

本项目使用 [MIT 许可证](LICENSE)。你可以使用、复制、修改、分发本项目，也可以：

- 将糯叽替换成自己的宠物或角色形象。

- Fork 项目，制作并发布自己的衍生版本。

分发副本或实质性部分时，请保留许可证要求的版权声明和许可文本。具体授权以 `LICENSE` 为准。

**替换形象目前需要修改素材和代码，还没有“一键上传换宠物”的入口。** 现有动画使用多张图层、不同姿态和固定坐标；完全不同的形象通常也需要调整动作位置。我们整理了 [替换形象与二改指南](docs/CUSTOMIZATION.md)，说明当前加载哪些素材、尺寸是多少、从哪里改。

欢迎在衍生版说明自己的修改，并保留原版来源介绍；这项介绍建议不额外增加 MIT 的许可条件。你新增的图片、音频或其他素材，请使用自己有权使用和分发的内容，并注明适用的授权。

## 实现与数据

| 文件 | 负责什么 |
| --- | --- |
| `index.js` | 酒馆事件、触摸拖动、气泡定位、设置和状态衔接 |
| `companion.js` | 台词、时间、今日统计与专属台词继承 |
| `pet-renderer.js` | Canvas 绘制、图层、动作和姿态 |
| `settings.html` / `style.css` | 扩展设置与样式 |
| `assets/` | 形象素材及部分处理源图 |
| `preview.html` | 动作预览页 |
| `tools/` | 素材处理与验证脚本 |

糯叽不会额外调用模型，不增加模型 token 消耗，也不向外部服务发送聊天正文。运行时会从你的酒馆加载自身脚本、设置模板和图片资源；没有内置遥测或第三方追踪。

自定义台词和当日去重记录随酒馆账户的扩展设置保存。今日统计不保存聊天正文，只保留当天所需的角色／聊天标识和回复去重信息。多个设备或标签页同时写设置时，依赖酒馆自身保存机制，不提供实时合并统计。

正式聊天页限制绘制帧率，设置展开时进一步降频；页面切到后台时停止实际绘制。关闭糯叽会暂停动画，停用扩展会清理监听。
