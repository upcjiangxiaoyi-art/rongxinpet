# 糯叽 0.13.0 · 我在听与挥爪

## 使用

覆盖原糯叽扩展目录并刷新酒馆。在设置动作区点“听你说”和“挥爪”，也可以在输入框打字触发倾听。欢迎和拖动结束等原本会挥爪的场景现在也会真正抬爪。整次挥爪约 2.4 秒，完成后回到环境状态；打字和生成仍可中断。

开启“减少动态效果”时，倾听保持竖耳偏头，挥爪展示静止抬爪姿势。独立预览支持同样的动作。

## 图层与动作

倾听使用原有头颈柔性变形：脸作为整体旋转、胸口渐变承接，脚掌固定。两只耳朵先竖起，随后错开转动，周期约 3.4 秒。

挥爪从原始坐姿提取一只前腿，肩部固定，沿连续曲线弯曲肘部和前臂；抬爪阶段缩短纵向投影以表现屈肘，另一前爪保持在地上。两次招手由前臂角度的小幅变化完成。

新增的补毛只用于原前腿遮住的胸腹区域。两张最终图层是 assets/nuoji-wave-body-v1.png 和 assets/nuoji-wave-leg-v1.png；使用时只加载这两张 PNG。所有旧 PNG 均保留原始字节。tools/build-wave-assets.mjs 可离线重建，需要 @napi-rs/canvas。

## 验证范围

- 新动作检查：抬爪位移、肩部固定、肘部变形无倒折、招手幅度、左右耳朵变化、减少动态效果。
- 控制器计时检查：短于 2.4 秒的挥爪请求会保留完整动作时间，结束回到待机。
- 蹭蹭 421 相位及互动打断检查、行走 4,000 相位回归通过。
- 使用生产 Canvas 绘制检查连续动作、脸部原像素与承重爪底。
- 当前环境未运行真实 SillyTavern 或手机浏览器；真机上的手势、加载速度和流畅度仍需要安装后验收。

## 新素材来源

使用内置 ImageGen 编辑原始 nuoji-base-v1.png。第一条提示要求只移除画面左侧前腿并补出其后的纤细银白胸腹毛，保持脸、耳朵、尾巴、其他腿、比例和构图。第二条提示将生成结果的棋盘背景替换成纯 #00FF00，以便可靠抠出补毛轮廓。未使用 CLI/API 生成。

生成结果保留为 assets/nuoji-wave-repair-green-v1.png，离线构建脚本只将前腿范围内的像素合入原身体；脸部不取自生成结果。
