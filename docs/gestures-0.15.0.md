# 0.15.0 耳朵与挥爪修正

这次针对耳朵牵动半边头、帧间抽动，以及挥爪时重复爪子、旧腿边线和前臂压缩的问题。

## 耳朵

保留耳根以下的原始像素。上方耳尖整体旋转，连接耳根的区域使用平滑权重逐渐弯曲，耳根处位移回到零。听你说话时不再添加头部倾斜。左右耳仍错开响应；保留原有眨眼。

## 小胳膊

肩部、肘部、手腕和爪子分别定位。先确定肘部与前臂角度，再用接近固定的前臂长度推导手腕；爪子跟随手腕，只作轻微转动和统一缩放。一次抬起、招爪与放下共 3.7 秒。

站立前臂与抬起后的蓬松前臂只混合毛发纹理，两张图中均移除爪子，圆爪单独绘制一份。上臂放在胸毛后面，身体补毛范围覆盖原来整条前腿及边缘阴影，避免露出第二条长线。资产由已有素材与离线蒙版生成，运行时直接加载 PNG。

## 红蓝对照

`gestures-preview.gif` 三栏依次为动耳、本体挥爪、独立着色的挥爪图层与关节线。红色是上臂，蓝色是前臂，金色是爪子。颜色只是检查覆盖范围，不属于正式皮肤。采用 30 fps，共 144 帧；挥爪结束后留出待机时间。

## 验证与边界

- 两轮听觉动作逐帧比较额头与面部固定区域，排除眨眼层后像素完全相同。
- 完整挥爪采样中，前臂长度为 195.2649–205.2649 个原图像素，最短是最长的 95.13%。
- 承重前爪落点在采样中保持同一高度。
- 动作曲线、落地衔接、控制器计时和输入/拖动/生成中断检查通过；走路与蹭蹭回归通过。
- 这是二维分层变形，胸毛后的上臂包含投影压缩，并非完整三维骨骼。原生 Canvas 检查不等于 iPhone / SillyTavern 真机测试，仍需观察手机实际播放。

## 复现

安装 `@napi-rs/canvas` 后运行：

```sh
node tools/build-wave-assets.mjs
node tools/test-gestures.mjs
node tools/test-nuzzle.mjs
node tools/test-walk.mjs
node tools/test-layer-assets.mjs
node tools/render-gesture-check.mjs /absolute/path/to/frames
```

结构化渲染结果见 `gesture-checks-0.15.0.json`。
