# 0.16.0：用小幅探爪替代高举挥手

## 动作

前爪轻轻离地并向画面左侧探出，稍停后平缓收回。总时长 3 秒：0–0.85 秒轻抬，0.85–1.2 秒继续探出，1.2–1.5 秒短暂停留，随后回收，3 秒回到坐姿。

使用原坐姿中提取的完整前腿贴图 `nuoji-wave-leg-v1.png`。前腿和爪子共同绕胸毛里的支点作小角度旋转，全程不缩放、不切换前臂贴图、不单独旋转爪子。最大角度约 19 度。图像平面中爪心最大向外移动约 54 个设计像素、抬高约 12.5 个设计像素；500 像素设计坐标会随实际桌宠尺寸缩放。

身体用既有补毛图承接被移开的前腿。接近起落端点时，在很小的位移范围内恢复原始坐姿身体，避免补毛区域突然切换。耳朵绘制函数及听觉动作不改动。

## 接口与加载

设置和预览按钮改为“探爪碰你”。内部 `wave` 状态、`window.NuojiPet.wave()` 接口沿用；控制器时长来自 `WAVE_DURATION_MS`，现在为 3000 毫秒。减少动态效果时使用固定的轻探姿势。输入、拖动、生成等原有中断行为保留。

动作首次仅加载身体和完整前腿两张 PNG。前几版分段素材留作历史资产，不再由本动作加载。离线素材构建脚本仍可复现这些资源。

## 验证

- 逐 10 毫秒采样：上臂、前臂及爪子各点间距离不变，连续轨迹无位置跳跃，支点固定，结束回到原坐标。
- 原生 Canvas：144 帧、30 fps 的三栏预览，左侧动耳、中间本体探爪、右侧同一前腿按区域染成红/蓝/金色的诊断。它们不是分开运动的三块素材。
- 排除眨眼后，两轮听觉动作的额头/面部检查区域像素保持不变；支撑爪高度固定。
- 控制器计时、重播、输入/拖动/生成中断以及蹭蹭回归通过。

这是为现有二维坐姿素材设计的小幅平面动作，不模拟视频中的站立托举。原生 Canvas 预览不是 iPhone / SillyTavern 真机测试，实际手机观感待验收。
