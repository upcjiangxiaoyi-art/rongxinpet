# 0.17.0 歪头 wink 打招呼

用户确认放弃挥手和探爪，将打招呼改为头部表情。沿用原坐姿身体，不再加载此前的去腿身体或分离前腿素材。

## 动作时间

- 0–0.65 秒：轻轻歪头约 5.7 度。
- 0.65–0.85 秒：画面左侧眼睛渐闭。
- 0.85–1.22 秒：保持单眼 wink。
- 1.22–1.5 秒：睁眼。
- 1.85–2.8 秒：缓慢回正。

角度、位移和眼皮透明度均使用平滑曲线。脖子的形变在设计坐标 y=300 前衰减为零，腿和爪子不参与动作。耳朵、眼周覆盖层与脸共享同一个头部变换。听觉状态的耳朵曲线和耳根绘制保持不变。

## 单眼绘制

复用 `rongxin-closed-eyes-v2.png`，不重新生成整张脸。图片载入后创建一次 305×190 的缓存画布，以局部椭圆羽化遮罩保留画面左眼的闭眼区域。遮罩不覆盖另一只眼睛和鼻子。wink 期间屏蔽常规双眼眨眼节奏，以免同时闭眼。

闭眼过程使用原眼与绘制眼皮的短暂透明度过渡，并非完整的三维眼睑模拟。闭眼素材载入失败时保留睁眼的歪头姿势。减少动态效果时显示固定的歪头单眼表情。

原 `wave` 状态、`window.RongxinPet.wave()` 接口继续可用；界面文案改为“歪头打招呼”。动作时长统一为 2800 毫秒。此前挥爪资源仅作历史资产留在包中，不再由此动作请求。

## 检查

- 动作曲线：先歪头、再 wink、先睁眼、再回正；头部点间距离不变；腿爪坐标固定。
- 原生 Canvas 全周期检查：前腿与爪子区域像素一致；两轮听觉动作的额头/面部区域保持一致。
- 在相同歪头姿态下比较有无 wink 覆盖层：另一只眼睛和鼻子区域像素完全相同，明显变化像素 1215 个，集中在单眼局部。
- 蹭蹭和控制器计时、重播、输入、拖动、生成中断检查通过。
- 输出 120 帧、30 fps 三栏预览：我在听、打招呼、放大脸部。
